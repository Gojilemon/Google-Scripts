# MFA & AK/SK Manager (MFA & AK/SK 助手)

一款专为开发者和运维人员设计的 Chrome 扩展程序，旨在安全、高效地管理多因素身份验证 (MFA) 密钥和云服务访问密钥 (AK/SK) 对。

---

## 🚀 主要功能

### 1. MFA (TOTP) 动态码管理
- **实时生成**: 支持标准 TOTP 动态码，按每条密钥配置实时刷新。
- **参数兼容**: 支持 `otpauth://` 中的 `issuer`、`algorithm`、`digits`、`period` 参数。
- **多种添加方式**:
  - **手动录入**: 直接输入 Secret。
  - **二维码识别**:
    - **上传图片**: 识别本地二维码图片。
    - **截图扫描**: 在网页中框选区域识别二维码。
    - **剪贴板粘贴**: 支持 `Ctrl+V` 粘贴截图识别。
- **输入校验**: Secret 自动规范化（去空格、大写）并校验 Base32 格式。
- **实时预览**: 添加密钥时实时预览动态码，快速验证是否可用。
- **进度条色阶**:
  - 剩余 30s~15s：绿色
  - 剩余 <15s 且 >5s：黄色
  - 剩余 <=5s：黄色平滑过渡到红色

### 2. 安全备份与导入
- **YAML 加密备份**: 导出时输入口令，使用 PBKDF2 + AES-GCM 加密。
- **导入预览弹窗**: 导入前展示新增与冲突统计。
- **冲突处理策略**: 对 MFA 与 AK/SK 冲突可分别选择覆盖同名或跳过。
- **默认合并导入**: 不覆盖全部数据，按规则合并去重。

### 3. AK/SK 密钥对管理
- **集中存储**: 本地管理 Access Key / Secret Key。
- **快捷复制**: 一键复制 AK / SK，提升使用效率。
- **分类标注**: 支持描述名称，便于检索。

### 4. 个性化体验
- **深色模式**: 支持浅色/深色主题切换并持久化。
- **简洁交互**: Tab 切换、弹窗反馈、导入预览流程清晰。

---

## 🛠️ 技术实现

- **核心框架**: Chrome Extension Manifest V3
- **前端技术**: HTML5, CSS3 (Bootstrap 5), JavaScript
- **核心库**:
  - `jsQR.js`: 二维码解码
  - `otpauth.js`: RFC 6238 TOTP 生成
  - `Web Crypto API`: 导出备份加密（PBKDF2 + AES-GCM）
- **数据存储**: 使用 `chrome.storage.local` 本地存储（数据不离开浏览器）

## 📦 安装说明

1. 下载本项目代码。
2. 打开 Chrome 浏览器，进入 `chrome://extensions/`。
3. 开启右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择本项目根目录即可。

## 📝 使用技巧

- **快速添加 MFA**: 在网页看到二维码时使用“截图扫描”，可自动回填到新增表单。
- **加密备份**: 定期导出 YAML 加密备份，并妥善保管口令。
- **导入前检查**: 导入时先查看预览统计，再按需设置冲突处理方式。
